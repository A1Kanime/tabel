# Табель рабочих часов

Учёт смен для небольшой бригады: статичный сайт на GitHub Pages, Google Таблица
вместо базы данных, Google Apps Script в роли бэкенда. Ни сервера, ни домена,
ни оплаты — всё на бесплатных сервисах.

Каждый сотрудник видит только свой табель: изоляция сделана на сервере,
а не скрытием в интерфейсе.

```
Браузер ──► Apps Script (веб-приложение) ──► Google Таблица
   ▲                                              │
   └──── опрос каждые 7–15 секунд ◄───────────────┘
```

## Возможности

**Учёт**
- запись смены: дата, время начала и конца, часы считаются сами
- ночные смены через полночь учитываются верно
- журнал обновляется без перезагрузки, новые строки въезжают волной снизу вверх
- помесячный фильтр, итоги за период

**Личный кабинет**
- вход по фамилии с инициалами, пароль сотрудник задаёт сам при регистрации
- пароль хранится только как SHA-256 хеш с солью — прочитать его нельзя
- статистика месяца, полоса выработки к норме
- правка своих смен: время, часы, комментарий, удаление
- расчёт зарплаты: часовая ставка, коэффициент за часы сверх 8, вычет НДФЛ 13%

**Отсутствия**
- отметка больничного или отпуска с периодом
- панель «Кто отсутствует» с поиском, общая для бригады

**Контроль по трудовым нормам**
- не более 12 часов в сутки суммарно (8 ч смена + до 4 ч сверхурочных, ст. 99 ТК РФ)
- не более двух записей за день, дубликаты смен блокируются
- предупреждения при превышении 40 ч в неделю (ст. 91) и 120 ч сверхурочных в год

**Таблица**
- лист «Табель» — источник данных
- для каждого сотрудника автоматически собирается отдельный лист по фамилии:
  помесячные блоки, дни 1–31 в колонках D–AH, сумма в AJ

**Интерфейс**
- тёмное «жидкое стекло», живой градиентный фон
- фон перетекает от синего к красному по мере выработки нормы
- адаптация под телефон и ПК по типу ввода, а не по строке браузера
- на ПК — светящийся курсор вместо системного

## Файлы

| Файл | Куда |
|---|---|
| `index.html` | Корень репозитория. Главная страница |
| `code.gs` | Таблица → Расширения → Apps Script. Заменить весь код |
| `diag.html` | Рядом с `index.html`. Диагностика связи, нужна при проблемах |

## Установка

**1. Скрипт**

1. Создайте Google Таблицу → Расширения → Apps Script.
2. Выделите всё (Ctrl+A) и вставьте `code.gs`. В проекте должен остаться
   один файл, иначе два объявления `doGet` конфликтуют.
3. Поменяйте `SALT` на свою строку — до первых регистраций.
4. Выберите функцию `selfTest` → Run → разрешите доступ. В логе (Ctrl+Enter)
   появится имя таблицы и номер версии API.

ID таблицы указывать не нужно: скрипт находит её сам.

**2. Развёртывание**

Deploy → New deployment → Web app:

- Запуск от имени — **От моего имени**
- У кого есть доступ — **Все**

Именно «Все», а не «Любой пользователь с аккаунтом Google»: во втором случае
сайт заработает только у вас, остальные упрутся в страницу входа Google.

Скопируйте Web app URL, он заканчивается на `/exec`.

**3. Сайт**

1. Вставьте URL в `index.html`, строка `var API_URL`.
2. Загрузите `index.html` и `diag.html` в репозиторий (Public).
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Через минуту сайт открыт по адресу `https://<логин>.github.io/<репозиторий>/`.

## Настройки

В начале `code.gs`:

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `SALT` | — | Соль для хеширования паролей. После смены все пароли перестают подходить |
| `MAX_DAY_HOURS` | 12 | Потолок часов за сутки |
| `MAX_SHIFTS_PER_DAY` | 2 | Сколько записей допускается за день |
| `WEEK_NORM` | 40 | Недельная норма, только предупреждение |
| `YEAR_OVERTIME` | 120 | Годовой лимит сверхурочных, только предупреждение |

В начале `index.html`:

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `API_URL` | — | Адрес веб-приложения |
| `NORM` | 160 | Месячная норма: полоса в кабинете и цвет фона |
| `MAX_DAY_HOURS`, `MAX_SHIFTS_PER_DAY` | 12, 2 | Дублируют серверные, для подсказок в форме |

## Обновление

- Правили `code.gs` → Deploy → Manage deployments → карандаш → Version:
  **New version**. Адрес не меняется. Через New deployment появится другой URL,
  и сайт его не узнает.
- Правили `index.html` → залейте в репозиторий и откройте с Ctrl+F5.

## Массовый ввод прошлых смен

Кнопка «Открыть таблицу» в кабинете. Заполняйте колонки B–G: Дата, Сотрудник,
Начало, Конец, Часы, Комментарий. Колонку **id** можно оставить пустой, но
такие строки правятся только в самой таблице. Чтобы правились с сайта, впишите
в столбец A любые уникальные значения.

После вставки запустите `syncAll` — соберутся помесячные листы.

## Если связи нет

Откройте `diag.html` и нажмите «Проверить»: страница по очереди проверит
доступность Google, обычный запрос и обходной, и назовёт причину. Кнопка
«Открыть адрес напрямую» — решающая проверка:

- вкладка не открывается → домен `script.google.com` режет VPN или провайдер
- Google пишет об ошибке → развёртывание удалено, сделайте новое
- виден JSON `{"ok":true` → адрес живой, ищите блокировку в расширениях браузера

Сайт сам переходит на JSONP, если обычный запрос режется CORS или подменяется
страницей-заглушкой; в шапке тогда пишет «на связи · обход».

## Что стоит знать

- «Реальное время» — опрос раз в 7 секунд на ПК и 15 на телефоне. Настоящий
  push потребовал бы отдельного сервера.
- Доступ «Все» означает, что записать смену может любой, кто знает адрес сайта
  **и зарегистрировался**. Чужие смены при этом недоступны никому.
- Забытый пароль сбрасывается удалением строки сотрудника с листа «Сотрудники»:
  при следующем входе профиль создастся заново.
- Листы сотрудников перезаписываются целиком при каждой записи — править их
  руками бессмысленно, все правки вносите на листе «Табель» или через сайт.
- Отпускные и больничные в расчёте зарплаты не участвуют: калькулятор считает
  по фактически отработанным часам.
